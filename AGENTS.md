# litellm-dbt-mcp

Public proof of concept: a LiteLLM gateway serving dbt metadata tools via
dbt-mcp. Its vocabulary is in GLOSSARY.md and its decisions are in docs/adr;
read both first, and use the glossary's terms.

This repo is public. Everything committed here must make sense to an
outsider: write only material about this gateway, and keep internal names,
hosts, keys and content from private repos out.
